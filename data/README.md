## Addition: `addition/` (descriptors)

| File | Shape / Size | Contents |
| --- | --- | --- |
| `addition/descriptors.zip` | 609 MB (2.59 GiB unpacked) | 213 cross-sectional descriptors (`OrderedDict[str, Series]` indexed by `(date, asset)` across 6,128 tickers x 321 month-end trading days, 1999-12-30 to 2026-08-31). No industry labels. |

Notes for integration (see [docs/ADDITION_DATA_ASSESSMENT.md](../docs/ADDITION_DATA_ASSESSMENT.md)):

- Uses Deflate64 compression; unpack with `unzip` or `7z` (unsupported by Python `zipfile` and `bsdtar`).
- Descriptor dates are month-end trading days while the forecast calendar uses calendar month ends; join on `Period('M')` (exact date join matches 78/116 months).
- Per-field coverage and tiers are in `artifacts/addition/desc_field_coverage.csv` (generated by `tools/desc_field_coverage.py`).
