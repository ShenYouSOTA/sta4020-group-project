### Part 2 — 风险模型（软件包已交付，尚未接入真实数据）

- part2_risk_model/ 是已交付的软件包（import risk_model）。入口：forecast_risk(panel, as_of, *, factor_covariance, covariance_shrinkage, specific_shrinkage, dynamic_variance, integration_method, ...)，返回 N x N 的下一期股票收益率协方差矩阵。
- 输入面板契约为 RiskPanel：dates (T,)、asset_ids (N,)、returns (T,N)（超额收益率）、style_values (T,N,Q)、style_ids (Q,)、industry_membership (T,N)、industry_ids (P,)、market_caps (T,N)。面板须平衡、无 NaN，且 T >= 2，因为模型用 t-1 期的暴露作为解释变量来回归 t 期收益率。
- [上游 README](../part2_risk_model/README.md) 明确指出，仅在合成数据上做过测试，数据获取、清洗、缺失值处理及经济风格描述指标的构建均不在软件包的范围内。这些工作仍由 Part 2 负责人完成，且是项目的关键路径。

### Part 3 — 投资组合构建（脚本已切换输入路径，已在模拟数据上运行）

- part3_portfolio/Part3.py 通过命令行接收输入路径，默认从产物目录读取，因此不依赖当前工作目录：预期收益率来自 artifacts/part1（优先用验证后的面板，否则用原始面板）；协方差来自 artifacts/part2/P2_Covariance.csv；实际收益率来自 artifacts/part1/Actual_Returns.csv；输出写入 artifacts/part3。脚本生成 Portfolio_Weights.csv、OOS_Portfolio_Returns.csv 和 Forecast_Portfolio_Metrics.csv。用法详见 [Part 3 说明](../part3_portfolio/README.zh-CN.md)。
- 五种方法：均值–方差优化、全局最小方差、最大分散化、风险平价、Black-Litterman。默认设置为 PERIODS_PER_YEAR = 12、RISK_AVERSION = 5.0、MAX_WEIGHT = None、RISK_FREE_RATE = 0.0；每项均可通过命令行选项设置。优化算法的计算逻辑沿用交付版本，未作改动。
- 已交付的结果来自模拟数据：20 只占位资产（Stock_01 .. Stock_20），覆盖 2023-01 .. 2024-12 共 24 个月。作业指南要求至少 5 年（60 个月）的月度样本外数据，因此不能在报告中引用此次运行的数值。这是测试用例，不是实证结果。
- Part3.py 在控制台打印自身计算的四项未计成本的指标，仅供核对，不再写出汇总表。报告中的数值必须来自 Part 4，因为后者纳入了成本、1/N 基准和统计检验。

## 3. 产物接口

各部分之间一律通过长表或宽表 CSV 交接，且必须有明确的 Date 列。收益率统一用小数表示的月度简单收益率，不年化，不用百分数。所有日期均为实际收益率文件所列的自然月月末；月末 t 作出的预测，用严格晚于 t 的第一个月末对应的实际收益率进行评估。

| 文件 | 产出方 | 使用方 | 格式 |
| --- | --- | --- | --- |
| artifacts/part1/P1_Expected_Returns.csv | Part 1 | Part 3 | 宽表。首列为 Date，随后每个资产代码一列。数值为下一月的预期简单收益率。 |
| artifacts/part1/Actual_Returns.csv | Part 1 | Part 3、Part 4 | 宽表，列与预期收益率表相同。Date 为实际收益率所属月份的月末。 |
| artifacts/part1/P1_Candidate_Universe.csv | Part 1 | 所有部分 | 资产总名单。任何部分需要确定「这 50 只资产」时都读取此文件。 |
| artifacts/part2/P2_Covariance.csv | Part 2 | Part 3 | 长表：Date, Asset_1, Asset_2, Covariance。每个预测基准日对应一个完整的 N x N 矩阵块。矩阵对称，对角线元素为正，无 NaN，单位为月度。 |
| artifacts/part3/Portfolio_Weights.csv | Part 3 | Part 4 | 长表：Date, Model, Asset, Weight。只做多，每组 (Date, Model) 的权重之和为 1。 |
| artifacts/part3/OOS_Portfolio_Returns.csv | Part 3 | Part 4 | Date, Model, Portfolio_Return。仅供核对；Part 4 用权重重新计算收益率。 |

以下规则此前已造成协作摩擦，因此在此明确列出：

1. 资产池取三个文件的资产交集，至少包含 20 只资产。少于 20 只时，Part 4 会拒绝处理。
2. 资产代码必须使用供应商代码，与 P1_Candidate_Universe.csv 中完全一致。不得改动后缀，也不能假定资产在各文件中的顺序一致。
3. 任何文件都不得包含年化协方差或年化收益率预测；时间尺度统一为一个月。
4. 缺少某个月份属于错误，不能按零处理。Part 4 会报错，而不是填补缺失。
5. 不得悄悄改变现有文件的含义。需要变更时，应新增文件，并在上表注明。

`uv run sta4020-check-artifacts`（src/sta4020_project/checks.py）核验此契约中可自动检查的条款；每次提交集成变更前均应运行。

### Part 2 — 风险模型（关键路径）

- 构建面板适配器：针对候选池中的 50 只资产，从 data/monthly_returns.pkl 和 data/risk_free.csv 构建月度超额收益率，从 data/mcap.pkl 取得市值，并用价格和换手率数据构建风格暴露。
- 现有数据可构建的风格描述指标：规模（市值的对数）、动量（12-1 个月收益率，即剔除最近 1 个月）、短期反转（1 个月）、波动率和贝塔、换手率和流动性。缺少价值和质量指标；可以剔除，也可以使用代理指标，但要说明这一局限。
- 行业：数据不含行业分类。可以把所有资产划入同一行业，使行业块退化为市场因子；如果软件包允许，也可以移除行业块。确定一种做法后，在 Part 2 章节记录并将其列为局限。
- 对 Part 1 日历中每个预测基准日运行 forecast_risk，写入 artifacts/part2/P2_Covariance.csv。验证各矩阵块均对称、正定，并核对特质风险对角线是否一致。
- 校准与比较：用相同窗口比较样本协方差、Ledoit-Wolf 收缩估计与 Barra 风格因子模型；以各协方差估计对应的样本外实现波动率作为客观评价标准并报告。

### Part 3 — 投资组合构建

- 输入已接通：默认使用 artifacts/part1 和 artifacts/part2，可用各自的命令行选项覆盖。因此，只需运行 `uv run python part3_portfolio/Part3.py`。尚缺真实的 P2_Covariance.csv，目前该文件还不存在。
- 加入报告将声明的约束和参数设定：MAX_WEIGHT 权重上限（例如 5% 或 10%）、可选的换手率惩罚项，以及有说明依据的 RISK_AVERSION 取值。命令行选项已存在，但仍须选定数值并说明理由。
- 至少完成一轮敏感性分析：比较风险厌恶系数 2、5、10，并测试一个 Black-Litterman 变体，即使用不同的 tau，或用市值加权先验替代 1/N。
- 优化前应用 data/BLACKLIST.pkl 和 data/UNTRADABLE.pkl 中的可交易性掩码，记录每月剔除的股票数量。
- 不要把 Part3.py 内部计算的指标列为最终结果。

### Part 4 — 评估（本仓库负责的部分）

已实现：契约验证；四项必需指标，以及索提诺比率、卡尔马比率、胜率和换手率；使用相同日历与成本模型的 1/N 基准；Memmel 夏普比率差异检验；以 Newey-West t 统计量衡量的詹森阿尔法；精确归因（差距 = 信号 + 择时）；分阶段表格、权重诊断、三幅图及 Markdown 报告。

剩余工作，按顺序如下：

1. Part 3 交付当天即使用真实产物运行评估，以标签冻结首批结果（例如 reports/interim/）。
2. 成本敏感性：功能已接通（--cost-sweep 针对 0、10、30 和 50 bp 的单边成本生成 tables/cost_sensitivity.csv，并在 REPORT.md 中写入两张透视表）。仍须在真实产物上运行，并撰文说明策略排名在哪个成本水平发生反转。这是最有力的一项实践层面批判性分析。
3. 分阶段解读：2015 年股灾、2018 年风险收缩、2021-2022 年回撤、2023-2024 年。各阶段都要指出 Part 1–3 中哪项建模选择能够解释该结果。
4. 撰写归因分析：说明差距中有多少来自信号，有多少来自择时。一个只靠择时「获胜」的策略只算一个发现，不能算成功。
5. 权重诊断：有效持仓数、最大权重、换手率。权重集中是协方差矩阵病态时的典型表现，这正是报告需要通过 Part 2 对比来检验的现象。
6. 如有余力，可扩展：计算针对五种策略进行调整的折减夏普比率（Deflated Sharpe Ratio），并对表现最好的策略做现实检验（reality check）的自助法检验。
