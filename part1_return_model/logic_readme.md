# Return Model 构建逻辑

主模型基于**信号日已知信息**预测个股次月收益：在符合条件的沪深 A 股宽截面上筛选特征、训练模型，首次预测锁定 50 只股票后，每月在宽截面上滚动更新模型并输出固定池内预测。

```text
原始行情与交易状态 → 每月构造特征 → 已实现收益滚动训练
                                           ↓
                              首次预测锁定前 50 只
                                           ↓
                           每月更新池内预测 → 回测与导出
```

## 1. 训练、信号与成交时点

以首次建仓为例，后续每月沿用同一时点规则：

| 时点 | 操作 |
| --- | --- |
| **2014-11-28**（锁池时最新训练标签截止日） | 11 月收益已实现，对应 10 月信号日特征，纳入训练。 |
| **2014-12-30**（12 月倒数第二个交易日） | 收盘后构造特征并预测 2015 年 1 月收益，按预测降序锁定 50 只股票。 |
| **2014-12-31**（12 月最后一个交易日） | 按前一日信号设定目标仓位，结合当日交易状态模拟成交。 |
| **2015 年 1 月末** | 实现 12 月末建仓至 1 月末的收益，用于评估当期预测。 |

第 `t` 月信号预测第 `t+1` 月收益，训练使用最近 72 个已实现标签的月份。因信号日早于月末最后交易日，最新训练标签为上月收益；样本外期间已结束的月份逐月滚动进入训练窗。

## 2. 原始数据与特征构造

- **数据对齐：** 日度复权收盘价用于交易日历与日/周收益；原始月收益作训练标签与评价基准；成交额交易所后缀统一为 `.SZ` / `.SH` 并按交易日与股票代码对齐。
- **可评分截面：** 信号日须有有效价格、可交易且非黑名单、上月市值为正，且近 12 个完整月均有收益。
- **11 个候选特征：** 覆盖市值、成交额、多周期波动与收益、PCA 暴露及残差波动（PCA 基于截至上月末的 36 个月收益）。两套模型共用该候选池。
- **标准化与缺失处理：** 每月信号日将特征转为以 0 为中心的百分位排名分数；回归时缺失值填 0，计算 Rank IC 时仅保留有效配对。

### 11 个候选因子

特征选取参考课程[第 3 讲第 10 页](<../docs/lectures/STA4020_L3_Expected Return Modeling I.pdf#page=10>)与[第 5 讲第 10 页](<../docs/lectures/STA4020_L5_Expected Return Modeling III.pdf#page=10>)：

| 因子 | 经济含义 |
| --- | --- |
| 上月末市值 | 区分大小盘规模效应。 |
| 近 21 个交易日平均成交额 | 衡量近一月流动性与成交活跃度。 |
| 63 日波动 | 衡量约一季度的日频总波动率。 |
| 8 周动量 | 捕捉近两月价格延续或反转。 |
| 12–1 月动量 | 捕捉中长期趋势，跳过最近一月以剥离短期反转。 |
| 上月末至信号日收益 | 捕捉当月已实现行情强度。 |
| 5 日收益 | 捕捉近一周短期反转或延续。 |
| 12 周波动 | 以周频衡量约一季度的总波动率。 |
| 上月收益 | 检验单月尺度反转或延续。 |
| PCA 第一主成分暴露 | 衡量对市场主要共同因子的敏感度。 |
| PCA 残差波动 | 衡量剔除前三主成分后的特异波动。 |

### 因子筛选规则

每个候选在同一 72 个月窗口内检验：每月至少 100 只有效配对、至少 48 个月有效 IC，经 6 个月块重采样与 BY 校正后保留 $q \le 0.10$ 的因子。2014-12-30 锁池时入选 6 项（上月末市值、近 21 日均成交额、8 周动量、当月截至信号日收益、5 日收益、PCA 残差波动；63 日波动与 12–1 月动量的 q 值为 0.1329 与 1.0000）。样本外期间每月入选 5–9 项（中位/众数为 6 项）。若全部候选落选，预测回退至历史共同均值。

## 3. 主模型（IC + FM 岭回归）

1. **特征筛选：** 计算各特征与下月实际收益的 Spearman Rank IC，经 6 个月块重采样与 BY 校正保留 $q \le 0.10$ 的特征。
2. **逐月截面回归：** 每训练月在合格股票上拟合「当月特征 → 次月收益」（标签按 1%/99% 分位缩尾，斜率岭惩罚 0.10）。
3. **系数平均与预测：** 对过去 72 个月的截距和斜率取等权平均，乘以当期特征分数得到次月预期收益。

主 notebook 同时对比个股历史均值、宽截面共同均值与 FF5 风险溢价模型（详见 [主 notebook 第 2–4 节](notebooks/Part1_Return_Model.ipynb)）。

## 4. 样本外选股、配置与评价

2014-12-30 两个模型分别从 2,178 只可评分股票中选取预测最高的 50 只锁定池，2014-12-31 收盘首次建仓。**样本外评估覆盖 2015-01 至 2024-08 共 116 个月**，固定 50 只股票每月在池内调仓。

### 4.1 前 25 只等权配置

1. **月度更新预测：** 每月倒数第二个交易日重估模型，预测固定池 50 只股票下月简单总收益率。
2. **排序与选股：** 对当月有有效信号的池内股票按预测降序排列（并列按代码升序），取前 25 只（无有效信号的股票仅在预测表补共同均值，不参与排序）。
3. **等权目标：** 入选股票各分配 $1/25 = 4\%$ 目标权重，其余为 0；若有效股票不足 25 只，剩余资金留作现金。

### 4.2 月末调仓与收益核算

- **调仓执行：** 在当月最后交易日收盘模拟调仓。无报价或不可交易股票冻结原持仓；可交易黑名单股票目标清零；冻结仓位与费用占用资金时，对可交易目标权重同比缩减。
- **交易成本：** 买卖双边各按成交额收取 **20 bp（0.20%）**，计作费用率 $c_t$。
- **组合收益：** 股票权重乘以下月实际收益加现金乘以下月无风险收益得毛收益 $r^{\mathrm{gross}}_{t+1}$，净收益为 $(1-c_t)(1+r^{\mathrm{gross}}_{t+1})-1$。

### 4.3 评估指标与基准

- **预测精度：** 在同月有效样本上计算月均 Rank IC 与 RMSE。
- **组合绩效：** 计算 116 期复利净年化收益、年化波动与最大回撤，对比固定池等权基准（每只有效股票 $1/50 = 2\%$ 目标权重，同交易限制与成本）、中证 500 指数及 FF5 市场收益（见[主 notebook 第 6–7 节](notebooks/Part1_Return_Model.ipynb)与[树模型 notebook 第 5–6 节](notebooks/Part1_Return_Model_Tree.ipynb)）。

## 5. 浅层提升树对照

与主模型共用 11 个候选特征与 BY 筛选门槛（树深度 3，标签为去截面均值并缩尾的次月收益，预测时加回历史共同均值）。2014-12-30 独立锁定前 50 只股票，并在同池及交叉池上与 FM 基准对照 RMSE、Rank IC 与组合绩效（见[树模型 notebook](notebooks/Part1_Return_Model_Tree.ipynb)）。
